Kimi K3

适合长文档、知识工作、深度研究和长程编程任务的旗舰模型。

模型定位

把很长的材料一次放进来，让模型围绕同一批上下文持续分析、改写、提炼和推进。

基本档案

厂商 / 平台Moonshot AI / Kimi
模型名称Kimi K3
上下文1M tokens
模态文本、视觉理解、工具调用
价格口径¥20 / Input MTok · ¥100 / Output MTok · ¥2 / Cache-hit MTok
核验日期2026-09-15

适合任务

长文档与报告把长报告、访谈纪要、政策材料或合同草案放在同一上下文里做结构化整理。
知识工作适合做资料归纳、竞品信息拆解、观点提炼和多轮追问。
深度推理用于需要连续判断、反复校验、逐步收敛的分析型任务。
Agentic coding适合长程代码调试、重构、多步骤开发这类需要持续上下文的工程任务。

模型特色

1M tokens知识工作深度推理Agentic coding

  • 1M tokens 上下文：更适合一次性处理长材料，而不是靠多次复制粘贴补上下文。
  • 中文长文档友好：课程中可以用它解释“长上下文为什么改变工作方式”。
  • 工具生态：官方平台展示了搜索、Excel、代码执行等工具能力，适合讲“模型 + 工具”的组合。

使用边界

  • 长上下文不等于可以直接放入真实敏感文件；公司数据仍应走批准工具或本地 / 私有化流程。
  • 超长输入会显著影响成本和响应时间，正式使用前要用真实任务样本估算输入输出比例。
  • kimi-k2.5、moonshot-v1 与 K2 系列旧型号已下线；课程统一使用 Kimi K3 口径。
  • 模型能力和价格以官方平台当日显示为准，课程页只保留核验快照。
