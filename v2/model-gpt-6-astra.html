OpenAI

GPT-6 Astra

适合高难度端到端工作、代码、浏览器、工具调用和专业软件协作的旗舰模型。

模型定位

把模型当成能跨步骤推进任务的工作伙伴：理解目标、调用工具、处理中间状态，再把结果收束成可交付内容。

适合任务

复杂专业工作适合需要跨文档、跨工具、多步骤推进的高难度任务。
软件工程用于代码理解、重构、调试和较长链路的工程协作。
工具调用适合和 Functions、Web search、File search、Computer use 等能力组合。
多步骤 Agent适合演示从目标拆解到执行、检查、修正的完整工作流。

模型特色

gpt-6-astra1.05M128K tokensComputer use

  • Computer use：适合讲“模型不只是聊天框，也可以理解和操作软件界面”。
  • Responses API 生态：工具调用、结构化输出、流式输出、多 Agent 编排等能力更适合工程化工作流。
  • 可调推理强度：官方建议使用 low 到 max 等 reasoning effort 档位匹配任务难度。

使用边界

  • 账号与地区可用性以企业实际权限为准，不假设所有环境都能直接使用。
  • 高能力模型成本更高，日常批量任务应先评估是否能用更轻量模型完成。
  • 涉及真实公司数据时，仍以公司批准工具、权限和数据治理流程为准。
